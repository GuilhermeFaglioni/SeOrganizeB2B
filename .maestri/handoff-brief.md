# Brief — SeOrganizeB2B

## Product Description
Internal company organizer (similar to Jira/Clickup) for the founder's own B2B company.

## Core Features (MVP)
- **Kanban board** — task management with visual pipeline
- **Tasks** — create, assign, track, comment
- **Integrated calendar** — sync with Google Agenda
- **Documents area** — share and edit `.md` files within the platform (view + edit in-browser)

## Tech Stack Preferences
- **Ecosystem**: TypeScript (fullstack)
- **Database**: Supabase (free tier)
- **Deploy**: Vercel (free tier) or cheap VPS — to be decided with Architect
- **Constraint**: Maximize free-tier usage across all services

## Audience
- Internal team only (the founder's company)

## Constraints
- Free-tier-first approach
- Scope to be detailed with Product Partner
